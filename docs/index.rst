runir
=====

runir implements knowledge representations for planning (description logics, policy sketches and module programs) on
top of tyr, in C++ with Python bindings (``pyrunir``). The
`README <https://github.com/planning-and-learning/runir#readme>`__ introduces it; these pages document parts of it
in detail.

The rules the planning-and-learning libraries share are documented in
`brokkr <https://planning-and-learning.github.io/brokkr/>`__.
